# Xquik Social Research

Research public X posts, profiles, threads, followers, and trends through
documented REST or MCP routes.

## Install

```text
/plugin marketplace add alberduris/skills
/plugin install xquik-social-research@alberduris-marketplace
```

## Setup

Set `XQUIK_API_KEY` in the approved environment or secret store.

Use the Skill for bounded public research by default. It requires explicit
approval before private reads, writes, monitors, webhooks, or bulk jobs.
